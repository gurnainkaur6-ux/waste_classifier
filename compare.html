🤖 What Each Model Does
Decision Tree:

Classifies waste using a flowchart-like series of yes/no questions based on features.

Random Forest:

Combines predictions from many decision trees (ensemble method) for better stability.

SVM (Support Vector Machine):

Draws optimal boundaries that separate different waste categories in feature space.

Naive Bayes:

Uses probability theory to predict the most likely category given the input features.

ℹ️ About This Evaluation
  • Test Accuracy: Performance on the held-out 20% test set
  • CV Mean: Average accuracy from 5-fold cross-validation (more reliable than single test score)
  • CV Std: Standard deviation of CV scores (lower = more stable)
  • 95% CI: Confidence interval for test accuracy (accounting for test set size)
  • Confusion Matrix: Shows which categories the model confuses with each other
  • Learning Curve: Shows if the model would benefit from more training data
